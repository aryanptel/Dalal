Dalal AI 
========

Windows: Run the "DalalAI_Setup.exe" Installer or extract the Zip archive and double-click the executable to run.
macOS: Extract the .zip archive and run the executable.
Linux: Extract the .tar.gz archive and run the ELF executable.

For full setup details and requirements, refer to the documentation at the source repository (GUIDE.md and DETAILED_DESIGN.md).
